# Welcome to the ATHA Wiki 

**ATHA** is a safety and workflow layer for `pacman` on Arch Linux. 

While `pacman` is incredibly fast and powerful, daily package operations can sometimes be opaque. ATHA bridges this gap by focusing on three core pillars: **Safety**, **Transparency**, and **Auditability**. This wiki documents ATHA's operational behavior, release history, troubleshooting steps, and maintainer processes.

---

## Quick Start

Get ATHA up and running quickly:

```bash
# Install via AUR
yay -S atha

# Verify system health
atha doctor

# Simulate an installation (safe, no changes applied)
atha install --plan vim

```
