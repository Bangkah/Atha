# ATHA

Simple package manager wrapper for Arch Linux.

## Install

```bash
yay -S atha
```

## Usage

```bash
atha install <package>
atha remove <package>
atha search <package>
atha update
atha list installed
atha info <package>
atha doctor
```

## Features

- Wrapper for pacman
- AUR support (auto build)
- Simple CLI UX
